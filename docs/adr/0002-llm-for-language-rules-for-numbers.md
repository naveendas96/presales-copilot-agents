# ADR 0002: The LLM handles language, deterministic code handles numbers
**Decision:** The LLM extracts requirements and writes the narrative. Capability mapping uses a curated solution-pattern KB, and effort uses a transparent formula: base days per pattern, per-unit scaling, 12% PM and 15% contingency.
**Why:** Estimates go into commercial bids. They must be explainable line by line and must not change between runs.
**Consequences:** The KB needs curating, and that's where the practice's delivery experience lives.
